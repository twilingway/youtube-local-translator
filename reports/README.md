# Локальные результаты

Эта папка заполняется установкой моделей, замерами и браузерными проверками. Её содержимое, включая звук, видео, профили Chrome, журналы и конфигурацию runtime, в Git не публикуется.

Краткие результаты и границы проверенного: [docs/VALIDATION.md](../docs/VALIDATION.md).

Для работы сначала запустите `scripts/setup.ps1`: он создаёт здесь метаданные скачанных моделей, которые использует локальный сервис. После установки моделей сетевые обращения к облачным ASR/переводу/TTS не нужны.
